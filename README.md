# WB Discount Calculator

Расширение для Google Chrome, которое прямо на страницах [wildberries.ru](https://www.wildberries.ru) показывает аккуратную панель-калькулятор: вы вводите сумму продажи и желаемую сумму, а расширение мгновенно показывает точный процент скидки, который нужно отнять.

## Возможности

- Плавающая панель в правой части экрана на всех страницах `*.wildberries.ru`.
- Два поля ввода: «Сумма продажи, ₽» и «Желаемая сумма, ₽».
- Мгновенный расчёт точного процента скидки и абсолютной разницы в рублях.
- Кнопка «свернуть»: панель сворачивается в маленькую круглую кнопку у правого края, можно развернуть в один клик.
- Состояние (значения и свернуто/развёрнуто) сохраняется между перезагрузками страницы через `chrome.storage.local`.
- Подсказки на русском языке, обработка некорректного ввода (нулевая или отрицательная сумма продажи, желаемая сумма больше продажи — тогда выводится требуемая *наценка*).

## Формула

```
процент = (сумма_продажи − желаемая_сумма) / сумма_продажи × 100%
```

Например, при сумме продажи `1500 ₽` и желаемой сумме `1200 ₽` расширение покажет `−20%` и разницу `300 ₽`.

## Установка (режим разработчика)

1. Скачайте/клонируйте репозиторий:
   ```
   git clone https://github.com/moyel0/wb-discount-extension.git
   ```
2. Откройте в Chrome `chrome://extensions/`.
3. Включите переключатель **«Режим разработчика»** в правом верхнем углу.
4. Нажмите **«Загрузить распакованное расширение»** и выберите папку с этим репозиторием.
5. Откройте любую страницу на `wildberries.ru` — панель появится в правой части экрана.

## Использование

- Введите сумму продажи и желаемую сумму — результат обновится автоматически.
- Кнопка-стрелка в шапке панели сворачивает её. Чтобы развернуть, нажмите на круглую кнопку у правого края страницы.
- Кнопка «Сбросить» очищает оба поля.
- Клавиша `Esc`, когда фокус внутри панели, тоже сворачивает её.
- Иконка расширения в панели Chrome тоже переключает видимость панели на текущей вкладке Wildberries.
